🏋️ GAINZ 4-Day Split

Notion sync

Check-ins save on this phone instantly. Paste your Zapier webhook URL below and they'll also land in your GAINZ Check-ins Notion database.

Stored only in this browser — never in the page or the repo.

Setup (one time, ~5 min)

  1. In Zapier, create a Zap — Trigger: Webhooks by Zapier → Catch Hook. Copy the webhook URL and paste it above, then Save.
  2. Action: Notion → Create Database Item → database GAINZ Check-ins. Map fields: Name ← name, Date ← date, Day ← day, Exercises ← exercises, Sets ← sets, Source ← source.
  3. Test the Zap, then turn it on. Every check-in now appears in Notion.
